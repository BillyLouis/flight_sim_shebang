# Dashboard configuration & info
### This dricectory archives all UX/UI interfaces which are:
- XAML Dashboard
- C++ & C# Joystick code
- Mechatronics chair
- Cockpit Airframe


### XAML DASHSBOARD:
The dashboard is divided into 3 categories:
- The Home Page
- The front board (dashboard: radar, etc ..)
- The Control board (engines, landing gear, etc...)
- The Cabin Screen (All controls in the cabin: temperature sensors, etc ...)


### C++ & C# Joystick code
All libraries to render the joystick operational. 
Joystick brand is: logitech X3D (Extreme 3D Pro)

### Mechatronics chair
Chair that mimics the movement of the joystic whether it is Pitch | Yaw | Roll

### - Cockpit Airframe
Counterweight, mechanical frame that holds the whole system suh as the chair, the screen monitor, all electronics and the computer.
